# PocPet 1.8.0 · 新日常、厨房与存档过渡

这次更新采用 UI v2，加入厨房与一起游戏，并开始使用精简的 JSON 新存档。应用版本仍为 1.8.0。

## 新玩法与主页

- 厨房上线：14 道食谱、16 种料理，支持批量制作、厨具解锁、初尝记忆和料理技能心心加成。
- 简化厨房导航，保留食谱本、厨具和试吃留言；点击菜谱打开制作弹窗，关闭后返回菜谱列表。
- 制作过程使用独立弹窗，投料、加工和装盘配有操作动画与音效；完成后展示料理与本次收获。每次成功制作获得 1 点料理经验，首做新食谱额外获得 5 点，批量制作计一次。
- 新增廉价白米饭，仅补饱腹；草莓饼干千层消耗大量苏打饼干，部分甜点改用草莓牛奶。
- 一起游戏包含翻牌、抛接球和吹泡泡，Lv.3 解锁，加入音效、动效和独立收获弹窗。
- 抛接球每局消耗一个玩具球，主动滑动抛球让移动中的伙伴接住；吹泡泡节奏加快。
- 恢复清洁旁的快捷玩耍，可直接消耗体力提升心情。冒险入口已预留，暂未开放。

## 界面与日常节奏

- 小窝使用新的房间背景、固定高度信息栏和五色状态圆环。花园、伙伴日程与纪念册同步采用新版布局。
- 首页保留做饭、小游戏、花园、日程、专注、打工、商店、朋友卡、扭蛋、成就、梦想及纪念册入口；冒险暂未开放。
- 设置成为独立页面，提供本机保存的主题偏好。喂食、购买、收获与领奖等操作接入浮动通知及最近消息记录；通知独立浮在最上层，不挤占弹窗高度。
- 朋友卡（原搭子卡）和双扭蛋采用全屏弹窗；扭蛋加入机身与物品图标摇晃，保留原交易、保底、跳过和防连点逻辑。
- 商店与背包采用白底物品格子和选中详情，支持分类、批量操作及互相切换，搜索栏暂时隐藏。背包默认打开商品栏，料理按食材价值优先排列；每行四格、放大图标，名称和数量显示在边角。
- 种植园直接在上方五块土地卡片显示进度并完成种植、浇水、施肥、收获及管理，移除下方重复详情。
- 小窝天气可点击查看天气、季节与种植影响；提高心心及提示文字对比度，日程中的角色保持不透明。商店、朋友卡与扭蛋入口移到花园上方。
- 暂时隐藏心心兑换金币入口，以及尚未完整实装的小风景和餐盘装饰选项。
- 食材独立分类，苹果、牛奶等可食用原料同时保留食物入口，共用库存；厨房补货可返回原菜谱。
- 伙伴日程的短／标准／长基础时长改为 20／60／120 分钟，原有技能加速继续生效。
- 小游戏基础心心随角色等级成长：Lv.3 约 5 心、Lv.50 约 50 心、Lv.99 约 150 心，接球为三倍，已有加成另计；不增加每日收益次数限制。
- 料理主要产出食物，制作心心减少，并随料理技能提高。
- 完整玩一局接球／翻牌，分别获得 1 点运动／学习经验；成功浇水、施肥或收获获得 1 点园艺经验。失败、放弃或重复领奖不发经验，满级后不再增加，也不计入日程完成次数。
- 优化手机网页存档下载提示，在设备支持时提供文件分享入口。

## 存档兼容

- 1.8 已开始使用新版存档。建议在升级 1.9 前，进入「设置 → 存档与恢复」导出并保留一份新版存档文件。1.9 仍兼容旧档并支持转换；2.0 将只读取新版存档。已有旧备份文件不会自动改写，请保留原文件。
- 新导出的 `.pocpet` 为紧凑 UTF-8 JSON（`schemaVersion: 2`），取消文件混淆和 Base64。新版可读取旧 JSON、旧转码、Mint 与旧云档；转换后请使用升级后的客户端继续游玩和同步。
- 本地保存、导出、自动备份和云存档共用精简数据；角色、物品 ID、Mod 身份、统计、回忆、随机序列、保底、冷却与奖励防重数据继续保留。
- 扭蛋明细仅在当前会话显示，重新载入后清空；最近提示、临时动画、料理制作结果不进入存档。选地、摆盘、小游戏外观及界面提示偏好保存在本机。
- 首次迁移保留独立的格式转换前原始副本，已有恢复点仍可使用；预览和格式转换不写入存储。写入失败时保留原档并暂停自动保存。
- 旧日程仅迁移提速一次；小游戏读档暂停，恢复时不重复扣球或发奖，已完成奖励不重算。
- 修复异常厨具／小游戏解锁列表导致整份存档无法读取的问题，修复小游戏刷新后意外暂停、点击退回的问题。
- 来自不支持的新版本的数据会明确提示升级，不会忽略新模块进度后覆盖保存。未来冒险将独立声明模块版本及最低读取版本。

## 云存档

- 保留现有 ZIP/DEFLATE + Base64 传输及 A/B 两份副本，继续读取旧云档；压缩内容统一为精简新格式。
- 每块由 960 扩至 1024 字符，每份仍最多 60 块，可用载荷上限提升至 61,440 字符，不增加占用键数。
- 上传前检查大小，写入后读回校验，再切换生效；设置显示容量使用情况。完整游戏数据未变化时跳过重复上传，游戏时间和结算字段参与比较。
- 超限时保留当前云档并提示导出本地备份；损坏副本可回退，来自更高版本的有效云档须升级客户端读取。

## 旧档补偿与箱装饼干

- 本机升级、手动导入或云端恢复的有效旧格式存档，首次迁移保存成功后自动获得 120 块苏打饼干和 10 个草莓牛奶，相当于三箱饼干。新建进度不适用。
- 补偿按存档及本机记录防重，刷新、改名、换外观或在同机重复导入同一旧档不会追加。补偿不占每日免费领取次数，也不计购买成就。
- 单项库存上限为 9999；补偿超出空间的部分随存档保留，腾出空间后自动补发。
- 商店新增「一箱苏打饼干」（`soda_biscuit_box`），常规售价 500 金币。购买后直接获得 40 块苏打饼干，不产生箱子库存，可用于喂食和厨房。
- 箱装商品同时显示在食物和食材分类，支持批量购买及每日折扣；库存空间不足时不扣款、不消耗优惠。箱装规格不进入邻居送礼和随机掉落池。
