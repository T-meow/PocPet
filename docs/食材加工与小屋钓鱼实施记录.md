# 食材加工与小屋钓鱼实施记录

## 已批准范围

- 钓鱼小屋统一选择四片水域；探索固定发现、修建永久直通，18 种鱼。
- 16 种菜地作物，12 种定向野生食材，7 种即时批量加工；鲜奶初始售价 18。
- 小麦种子 24、8 小时收获 4、1 小麦加工 2 面粉，回收价小麦 3／面粉 4。
- 普通奶配方每批明确选择鲜奶或原有 AD 高钙奶；草莓配方仍指定草莓牛奶。
- 牧场每日照料和收获后任选一瓶奶。地区采集共用每日 3 次；珍稀调查各自累计 3 次得 1 份。
- 食谱分类、稀有度、组合筛选、排序及统一恢复数值；保留技能、奖杯、60% 饱食溢出规则。
- 客群 50% 普通、25% 美食、15% 收藏、10% 慷慨游客；保留 5–20 分钟、锁定挂牌价格和已有离线结算。

## 现场与实施约束

开始时已有市场、社区场景、计时及相关验证脚本的未提交改动和未跟踪文件；在其基础上增量修改，不回退、不清理。菜地沿用现有单地块与生产时间戳，不新增地块或重置生产。图像继续使用现有素材和代码占位，画面由用户人工验收。没有提交、发布或打包授权。
