# Toy 平台使用参考

Toy 版提供平台登录、云存档、相册与分享能力；普通 Web 和原生客户端保留各自的本地功能。平台适配代码集中在 `src/platform/`。

## 云存档

在已登录的 B 站 App 中打开「设置 → 存档与恢复」，可上传当前进度或读取同账号的云端存档。恢复先展示导入预览：取消保留本地进度，确认后留下导入前备份。旧 JSON 和受支持的 `.pocpet` 格式导入后仍可上传。

未登录、断网或平台不可用时显示失败状态，不覆盖本地存档。云端采用分片与版本清单，写入中断、损坏回退和高版本保护通过 `npm test` 的内存替身检查；实际登录与跨设备操作由人工确认。

从未上传、创建已超过三天的存档可显示备份提醒。关闭后当天不重复弹出，设置提示保留；选择七天后提醒会同时隐藏提示。提醒可在设置中关闭，上传成功后按云端上传时间重新计算。

## 分享与纪念

- 设置可生成宠物档案卡，并导出最近的年度纪念卡；扭蛋结算可保存结果卡。
- B 站 App 使用平台相册和分享面板，Toy Web 使用 JPEG 下载、二维码或平台链接。
- 普通本地 Web 不分享 localhost 或本地测试地址。
- 作者卡与视频入口分别跳转对应内容。关注奖励为一次性十张扭蛋券，领取状态随存档和云端标记保存；旧作者链接奖励与关注奖励使用不同标识。

## 构建入口

使用 `npm.cmd run package -- --type toy` 生成 `release/pocket<版本>-toy.zip`。Toy HTML 引入官方 SDK，标准版不引入；资源使用相对路径。打包阶段统一校验版本、edition、revision、SDK 与资源清单，详见 [打包参考](打包流程与统一脚本.md)。

登录、相册权限、分享面板和实际移动端交互需要在平台环境中人工确认。生成本地 ZIP 不会自动上传或发布。
