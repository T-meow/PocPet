## 本轮统一制作要求

- 按现行美术规范采用 C 组：圆润 Q 版、深巧克力褐顺滑描边、左上光源、适量赛璐璐明暗与轻渐变，48 px 可辨认。默认纯文生图，不自动上传角色或旧道具。
- 默认参数为 mxai、Sunburst、medium、1K、1:1、1 张；当前静态技能表可能缺 Sunburst 名称，生成对话先核对实时模型列表与 dry_run，不静默换模型。本轮未查询服务或报价。
- 一张原图表 4×4；A–H 填满，I 仅前 5 格，J 仅前 7 格，空格留白。纯白底，不画卡片、网格、文字或地面阴影。表中名称仅供提示词定位，不能印到图上。
- 先保存并展示模型原图，用户确认前不切分、裁切、去底、缩放、生成对照图或接入。后续具体确认在任务内持续有效，不重复索要。画面与触控由用户人工检查。
- 获准加工后：256×256 RGBA PNG 母版，主体最长边约 184 px；道具运行图 128×128 透明 WebP，保留 PNG 源与原图，Lanczos3 缩放、高质量轻度压缩。装饰建议运行图 256×256，另接专用映射。
- 料理的盘／碗／杯／盒随成品一体画，不为 plain／flower／stars 重画三份。现有 `dishPresentation` 的占位类型和统一偏移不能当新图实测数据，接入时按实际器皿更新。
