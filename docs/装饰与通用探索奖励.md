# 装饰与通用探索奖励

装饰在农场「旅途与日常」统一管理；已制作的装饰也可从场景打开同一详情。星辉穹顶及宿主设施尚未开放的装饰陈列在旅途角。首次配方见 [工具与珍宝参考](生产探险道具与珍宝数值表.md)。

## 永久效果

七件装饰制作后同时生效，首次配方不变，最高十级。Lv.1→5、Lv.5→10 分段线性增长，内部计算保留一位小数，界面显示整数。

| 装饰 | 效果 | Lv.1 / Lv.5 / Lv.10 | 高级升级珍宝 |
| --- | --- | --- | --- |
| 琥珀叶影灯 | 邻里及特产订单金币 | +5% / +10% / +20% | 溪光海蓝宝 |
| 鎏金社区铭牌 | 新上架售价 | +5% / +10% / +15% | 风丘日光石 |
| 鎏金社区铭牌 | 包场成交机会 | +5% / +25% / +50% | 风丘日光石 |
| 溪光水景 | 作物生长时间 | −5% / −10% / −20% | 溪光海蓝宝 |
| 日光风向标 | 鸡舍、牛棚生产周期 | −5% / −10% / −20% | 风丘日光石 |
| 古树绿宝挂饰 | 成功普通采集追加一份物产概率 | 10% / 20% / 35% | 雾松祖母绿 |
| 月潮贝灯 | 抛竿后的咬钩等待时间 | −10% / −20% / −30% | 月潮珍珠 |
| 星辉穹顶模型 | 挂机地区珍宝概率 | +1 / +3 / +6 个百分点 | 星辉蓝宝石 |

铭牌售价加成按当前报价相乘，采购与自产同名商品统一报价；旧货架补货保留原价。包场加成为相对比例，每级 +5%，与烹饪技能提供的最高 +45% 相加后乘到包场期望额度上，实际成交概率最多 100%；适用于全摊商品，普通交易与 8–20 份大单沿用原成交速度，规则见[食材与料理数值表](食材与料理数值表.md)。挂饰每个实际采集机会最多追加一份普通物产，珍宝勘探、种子、任务物品与通用探索物品不参与复制。

## 探索结算

采集次数每小时恢复 1 次，上限 72 次；挂机出发预留每小时 1 次，预留计入总容量，返程退还未使用次数。常规奖励只受采集次数限制，不再发行每日奖励券；免费观察只推进故事，首次奖励与见闻里程碑仍为一次性。

| 探险档位 | 手动每次采集固定金币 | 挂机每小时固定金币 |
| --- | ---: | ---: |
| 第一档 | 20 | 16 |
| 第二档 | 40 | 32 |
| 第三档 | 80 | 64 |

第二档需溪谷全部地标、一级营地；第三档需溪谷二级营地、累计采集 80 次与溪光水景。金币应用地区倍率 100%／125%／150%／175%／220% 后向下取整；每次采集提供基础爱心 1，应用既有成长与领取加成。货币先记入行程，返程领取时到账。

金币堆、琥珀、古老金条的兑换价保持 360／600／1000。普通随机掉落保留旧满额度时的单次概率，取消剩余额度截断：按档位面值 150／300／600，乘地区倍率并向下取整，再乘 25% 及份额（溪谷手动 50%、其他地区手动 100%、挂机每小时 40%），除以均价 1960/3 得出命中概率，命中后三者等概率选一。固定金币与可兑换物品分别展示；预约、退款和预览不抽取。

全部地区提供当地材料、普通野外食材、松脂和海玻璃等挂机目标，目录由 `explorationResources.ts` 统一生成。普通食材按手动每次／挂机每小时分三档：莲子、山栗、野柠檬、松子、蛤蜊、海虾为 3／2；野菇、蜂蜜、林莓、海藻为 4／3；香草、嫩笋、野洋葱、木耳、海盐为 6／4。材料每小时 2 份，木料与石料目标每小时同时获得木材 3、石材 2。种子按作物定义识别，食用莲子可以挂机；种子及研究食材松茸、茶叶仅手动获取。

挂机自动补给为 10 金币／份，烹饪每级减费 3%、最高 30%，仅在确认出发时扣费。标准补给可一键补齐，也可自选食物。提前返回先吃剩余食物，吃饱后分享给邻居；不退食物和费用，次数及仓库待领收获分别保留。

挂机每完成两小时判定一次地区珍宝：基础概率为 `clamp(5 + 15 × (配餐评分 / 标准评分 − 1), 5, 20)`，再加星辉穹顶效果，最高 26%。基础、装饰与最终概率在出发时一起保存。新挂机按地区独立累计未获得次数，连续 9 次未得后的第 10 次必得，随机获得清零；跨日、跨行程保留，手动勘探不影响计数。提前返回未满两小时不计数。地图设置与结算显示概率、计数和保底命中情况。

界面中的属性、恢复量和概率统一显示整数，倍率使用整数百分比；计算及存档保留原有精度。小于 1% 的非零概率显示「<1%」，大于 99% 且不保证成功的概率显示「>99%」，避免误示为不可能或必得。表格中的近似概率不用于结算。

金币堆、琥珀和古老金条仍按原随机规则，没有新增保底。旧溪谷见闻迁至入口探索的六阶段分支，6／12 条见闻里程碑、首个入口宝藏沿用旧计数及已领奖记录。

## 保存与时点

- 旧装饰拥有列表保留，缺等级的已制作装饰视为 Lv.1。
- 订单接取、商品上架、播种、抛竿和探索出发时锁定对应报价、奖励或生产效果；包场机会使用结算时的烹饪技能和铭牌等级，经营操作前先结清已到访客人。
- 装饰升级先结清已经发生的牲畜生产，保留本轮截止时间，下一周期采用新效果。
- 更新时旧手动行程直接成功完成，保留取得物品并结清该地标的一次性完成奖励；旧挂机按完整预定时长成功结算，忽略健康不足返程。旧巡路按成功回执保留已有物资与工具。冻结存档在解冻后处理。已有待领回执不重新抽取。
- 旧采集次数先按三小时周期结清，再将剩余恢复进度按 3:1 换成一小时周期，次数不直接翻倍。旧回执领取后，剩余有效凭证按未付固定金币、随机奖励期望值及未领爱心一次补偿；已锁定地区沿用，未锁定按溪谷。预算版本 2 和未入账补偿一起保存，满币时保留欠款。
- 采集结算使用持久化消费序号、固定货币和随机掉落结算序号防重，保留教程、首次奖励及见闻里程碑的已领取记录。
- 存档模块版本、行程规则与压缩兼容约束统一见 [CodeWiki](CODEWIKI.md)。
- 手动行程记录地区、地标与稳定阶段标识，旧采集目标仅用于兼容；旧通关地区迁为全部地标完成，不补发首通奖励。挂机保底计数与已结算两小时段同时保存。
- 满仓保留待领物资，金币达到安全整数上限时保留未付酬谢；兑换或交单无法足额付款时保留物品。
