# 装饰与通用探索奖励

装饰在农场「旅途与日常」统一管理；已制作的装饰也可从场景打开同一详情。星辉穹顶及宿主设施尚未开放的装饰陈列在旅途角。首次配方见 [工具与珍宝参考](生产探险道具与珍宝数值表.md)。

## 永久效果

七件装饰制作后同时生效，首次配方不变，最高十级。Lv.1→5、Lv.5→10 分段线性增长，保留一位小数。

## 探索结算

金币堆、琥珀、古老金条的物品 ID 与兑换价 360 / 600 / 1000 不变。新酬谢凭证支付原金币的 75%，另以 25% 期望价值分配独立实物掉落；三种物品等概率，每个实际采集机会最多一件。概率为本次期望价值除以三者均价 1960/3。

沿用每日四份、保留三天的凭证。溪谷手动每次分配半份，其他地区一次一份；挂机每小时 40%，每份最多用 80%。混合玩法扣剩余额度，未命中也扣额度。费用与实物额度分别记录，沿用地区倍率。预约、退款、免费散步和展示预览不抽取；结果进入既有行囊、溢出、回执及分批领取流程。

挂机每完成两小时判定一次地区珍宝：基础概率为 `clamp(5 + 15 × (配餐评分 / 标准评分 − 1), 5, 20)`，再加星辉穹顶效果，最高 26%。基础、装饰与最终概率在出发时一起保存。手动勘探的调查进度与判定规则不变。

## 保存与时点

- 旧装饰拥有列表保留，缺等级的已制作装饰视为 Lv.1。
- 订单接取、商品上架、播种、抛竿和探索出发时锁定效果。
- 装饰升级先结清已经发生的牲畜生产，保留本轮截止时间，下一周期采用新效果。
- 旧配餐、旧在途行程和旧凭证继续兑现原规则，已生成回执不重新抽取；旧奖励核销对应预算。
- 采集结算使用持久化序号及凭证额度防止重复抽取，保留教程、首次奖励及见闻里程碑的已领取记录。
- 保存模块兼容版本为 adventure 7、expedition 4、community 10，继续使用既有压缩流程。
