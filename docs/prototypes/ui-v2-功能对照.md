# 原有功能核查与入口对照

本次按现有 `src/ui/` 页面、操作回调和相关核心定义核查，已补回下列遗漏。交付仍是 `ui-v2.html` 的离线假数据原型；正式游戏代码与存档不变。

## 已补回或调整

| 功能 | 核查结果与新版入口 |
| --- | --- |
| 邻居来访 | 从日程页移入主页「今日小事」。打开来访卡收下花束，物品入背包，近况记录来访；当天领取后隐藏。切换角色会显示其他伙伴来访。 |
| 每日心愿与回归 | 原型只演示喂食和摸摸。现补齐喂食、清洁、玩耍、摸摸、打工五种心愿，以及喂食、清洁、摸摸、睡觉四种回归目标；在预览设置选类型，完成并领取后隐藏。 |
| 伙伴日程 | 补齐今日可选安排、已完成标记、不可重复完成、技能成长后次日从 3 项扩展至 4／5 项、短日程仅金币奖励、技能等级与大师里程碑说明。邻居同行仍显示在对应日程里。 |
| 每日扭蛋券 | 补齐心愿、三次日程、日常邂逅的券来源和当天结算状态；三次日程必得券，另外两种来源展示 20% 机会的模拟结算，券实际入账且不重复发放。新手和关注礼包券数同步为现有定义的 10 张。 |
| 奖杯柜 | 原型遗漏了分档收藏。现展示四类各铜／银／金共 12 座奖杯，以及钻石奖杯，显示效果、解锁阶段和收藏进度；梦想阶段完成后联动。 |
| 传承 | 原型只有一次性支付。现补回 10%、25%、投满三档投入，进度保留，投入达到目标后完成本级传承；大额投入提供确认。 |
| 金苹果兑换 | 补齐兑换 1 个、10 个、全部，批量兑换确认和不足反馈；未解锁时保留可见的条件说明。 |
| 存档导入 | 原型只有内置示例。现支持选择本原型导出的 JSON、粘贴文本、检查、摘要确认、导入前备份、恢复导入前进度；失败和取消保留当前进度。 |
| 备份与文件 | 补齐单份备份导出、文件选择、授权过期与重新授权演示，以及存档文件分享入口。下载的单份备份对应所选记录。 |
| 异常恢复 | 补齐选择恢复候选、重新读取、查看及导出异常原文、转入文件／文本导入；保留新建进度确认。 |
| 状态与照顾 | 补回可点击的五项状态详情、体力恢复倒计时、低清洁睡觉提示和金苹果首次使用确认。确认金苹果使用后，该份演示进度不再重复提示。 |
| 专注 | 设置范围同步为专注 1—180 分钟、休息 1—60 分钟、1—8 轮；补齐忙碌、睡眠和状态不足的开始限制，睡觉暂停专注，首页使用所选时长。 |
| 分享、更新、版本 | 补齐应用分享与示例链接、版本发布记录、更新前备份、版本功能对照、云同步确认与提醒操作；设置保留新建进度入口。 |
