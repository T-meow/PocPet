# 新版 UI 原型验收说明

打开同目录的 `ui-v2.html` 即可使用。样式、脚本和 66 份素材均已内嵌，约 7.8 MB，可单独复制、离线打开。旧版 `home-grid.html` 保留。原有功能的补漏结果与入口位置见同目录 `ui-v2-功能对照.md`。

本次从 `main` 创建并切换到 `dev`，保留了已有工作区改动，未提交 Git。正式游戏接口、类型与存档没有改动。

## 快速入口

- **更多**：打开分组功能导航，进入所有页面；子页面顶部保留返回小窝和更多入口。
- **设置 → 外观与环境**：浅绿、暖杏、雾蓝、淡紫及自选点缀色；取色器和 HEX 输入同步。换色只调整页面底色、品牌和少量强调，功能卡片、资源、状态与纪念卡保持各自的颜色。天气与四季独立切换，也可点击小窝或花园的天气标签进入。
- **预览设置**：页面底部或更多面板进入。切换新手、综合日常、终局，以及普通版／B 站版、中英文；推进模拟时间，触发生日、节日、周年、回归、异常恢复、长通知、大数字和余额不足。
- 外观、环境、语言和版本独立于进度；切换角色或示例进度会保留。刷新页面恢复浅绿、晴天、秋季与综合日常进度。

通知独立浮在屏幕顶部，约 5 秒收起，可关闭、展开长文，并保存最近 20 条。展开时给页面和弹窗让出空间。背包与商店使用格子、信息、操作分离的布局；手机三列物品格子。花园桌面三列总览加右侧详情，手机两列总览加下方详情。

彩色风格调整：金币使用黄色胶囊，爱心使用粉色胶囊；五项状态使用橙、黄、蓝、紫、绿圆环，圆环内显示当前数值。照顾按钮、导航、物品分类、技能、梦想、角色及搭子卡分别使用固定配色。首页纪念卡保留粉蓝叠纸、黄色胶带和花朵贴纸；未解锁纪念插画时使用普通角色贴纸，解锁后才显示对应插画，详情与保存入口也检查解锁记录。

今日小事逐条隐藏已完成且已领取的事项；没有待办时隐藏标题和整个模块。有新心愿、邻居来访、可收获果实、日程待领奖或回归目标时重新出现。邻居礼物从主页领取，日程页保留同行安排。回顾改为彩色长卡，包含相伴天数、等级、活跃天数、照顾、物品使用、花园收获、完成日程、专注轮数、常做的照顾、技能和梦想成就。回顾页、预览和 PNG 导出共用海报内容，数据随演示操作更新。

验收解锁状态：新手与综合日常进度使用角色贴纸封面，终局进度显示已解锁插画；切换 Furo、Doro、mint 可查看各自封面。新手从零开始累积回顾数据，综合日常与终局提供不同的示例记录。

## 模拟边界

资源、库存、日程、花园、抽取和领奖共用一份内存状态。物品和成就定义及奖池来自现有项目；进度、掉落、计时及部分数值经过简化，便于验收界面，不作为正式玩法平衡实现。

存档文件使用独立标记 `pocket-ui-prototype-v2`，支持内置示例、选择原型 JSON 和粘贴文本导入。备份和“云端”只在当前原型内存中模拟；不连接账号，不读写正式游戏存档。文件授权及平台分享使用模拟流程；Mod 用示例包展示流程，介绍视频用可播放／暂停的本地分镜展示。更新下载仅展示结果，不下载或安装程序。名片、回顾、抽取结果和 CG 支持本地图片下载。
