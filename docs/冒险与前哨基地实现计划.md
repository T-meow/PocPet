## 一、定位与上线阶段

冒险成为后期主要玩法之一，连接现有照顾、厨房、背包、金币、小心心和金苹果。核心流程为：

**基地接取目标 → 准备行囊 → 探索与遭遇选择 → 中途补给 → 返程结算 → 建设基地、继续探索。**

- **1.9：前哨大厅与溪谷首个任务。** 大厅接入地图桌、伙伴与邻居形象、行囊准备、厨房与补给入口、旅行手账。每张地图的首个任务均为「入口附近探查」，本次仅溪谷开放，其他四图显示筹备中；溪谷可走完准备、遭遇、途中补给与返程结算。行囊仅在实际出发时转移库存。
- **首期地区拓展：溪谷后续任务。** 在入口探查基础上扩展地点、变化事件和基础基地项目。
- **地区扩展：五地区与挂机远行。** 沿用溪谷、风车山丘、雾松林地、潮汐海岸、旧观测站，各自提供特色产物、故事和基地。
- **终局扩展：长线远征＋基地经营＋伙伴委托。** 根据地区探索进度逐步开放，不要求先满级，也不以完成旧伙伴梦想为前提。

取消当前规划中的回合战斗、敌人血量、攻击技能及 Lv.12 战斗门槛，统一改为探索遭遇。五地区仍保留不同产出与探索主题，后续阶段不在本轮另行指定版本号。

## 二、探索、行囊与伙伴补给

### 节点探索

首张地图采用约 6～8 个节点、两条分支和一个明确终点。固定地标承载地区进度，变化事件提供重复游玩的差异。

推进消耗现有体力和饱食度，不另设独立步数。行动前显示消耗、条件和可预知结果；清洁、心情只承担少量情境反馈，健康不作为普通探索的常规扣除项。同一路线成本不随玩家等级同比上涨。

遭遇提供不同资源取舍，例如：

| 遭遇 | 可选处理 |
| --- | --- |
| 动物挡路 | 消耗合适食物引开；绕路增加状态消耗；放弃该支路 |
| 断桥 | 使用绳索；寻找浅滩绕行 |
| 浓雾岔路 | 使用观察工具辨认；沿已知路线绕行 |
| 被遮挡的遗迹入口 | 消耗体力清理；根据已发现线索走侧门 |
| 稀有足迹 | 使用指定诱饵继续观察；记录线索以后再来 |

主要路线始终有普通资源可以完成的处理方式。关键线索与捷径永久记录，后续探索可实际使用。

### 行囊与途中恢复

- 初始容量以 **4 份消耗品＋1 件工具**作为首轮调试基线；消耗品按份计数，工具可重复使用。
- 出发时将所选物品从仓库转入行囊，实际使用时消耗，未使用部分返程归还。
- 行囊容量限制随身补给；本趟发现物另行记录，不占补给格。
- 沿途可主动使用携带的食物和恢复道具，复用现有效果。用于引诱或交付的食物不同时触发喂食恢复、喜好奖励。
- 地图休息点提供明确、有限的休整机会，同一趟反复访问不重复恢复。
- 可随时安全返程，不额外收取返程体力；不足以继续时仍可补给或返回。

“仓库”指现有背包库存，不为每个基地另建一套物资仓库。

### 随机伙伴服务

由当前伙伴之外的内置伙伴随机出现，首期围绕 Furo、Doro、mint 配置，不增加独立商人角色。

| 服务 | 支付 | 实际行为 |
| --- | --- | --- |
| 购买随身补给 | 金币 | 从对方本次携带的有限商品中购买，放入行囊 |
| 请伙伴运输物资 | 小心心 | 从玩家家中已有库存选择补给，送入行囊空位 |

运输首版只支持**仓库到行囊**。确认时展示物品、数量和小心心费用，统一扣除仓库库存与费用并交付，不另加现实等待时间；库存、余额或容量不足时不扣费。

同一遭遇的伙伴、商品和服务额度保存后固定，重开页面不刷新。每次遭遇最多进行一次购买订单和一次运输订单。常规路线不依赖随机遇到伙伴才能完成。

## 三、奖励与金苹果的新价值

### 探索奖励

- 小心心：完成事件、探索目标与行程。
- 金币：委托、宝箱和特定资源路线。
- 道具：食材、护理用品、地区材料及有明确用途的特殊发现。

返程统一结算。提前返回保留已完成事件收益与发现，抵达终点另获完程奖励；每个节点每趟只结算一次，出发后立即返回没有完成奖励。

这取代旧手动探索原型中“只有完整探索才给小心心”的规则。挂机远行的进度奖励另按其行程规则配置，不能直接把手动节点奖励与旧远行收益重复叠加。

收益设计保留等级与既有增益的价值。赚钱路线应有合理净金币收益，材料路线侧重目标产物；首版不预设每日三次上限，通过真实消耗、路线长度和有效目标控制产出。

### 金苹果

当前金苹果已有恢复五项状态上限 50%、心心扭蛋、解锁后的固定兑心，以及伙伴梦想和共同纪念投入等用途。保留这些规则，新增两类价值：

1. **特殊探索消耗。** 在已发现的稀有足迹等指定遭遇中使用，保证开启一次对应的特殊观察事件，获得明确的发现或收藏进展。消耗前展示具体结果；不做“吃掉后只提高一点概率”，也不作为普通路线门票。
2. **永久基地项目。** 与金币、地区材料共同投入有限阶段的高级设施，解锁新的准备能力。首轮候选为额外工具位、扩展补给容量和提供目标线索的勘察设施；收益有上限，不叠无限产出倍率。

现有金苹果恢复五项状态上限 50% 的效果，直接用于长线补给，不再叠加免费行动次数。用于特殊事件或建设时作为交付消耗，不同时触发食用恢复。特殊探索主要提供定向发现、材料与纪念，不设计稳定消耗一颗赚回更多金苹果的循环。

具体价格、产量及金苹果消耗数量，在正式开发前单独完成经济核算。伙伴购买与运输费用、地图消耗和奖励、建设成本均为待验证参数，不作为已确认正式数值。

## 四、终局：远征、建设与委托共同循环

### 长线远征

将多个已解锁地区串为一次行程，首期以 2～3 段为基线。每段包含路线选择、遭遇和补给判断，到地区基地可以休整、保存进度，并选择继续或结束。

已完成路段保留收益，最终目标提供额外奖励，结束行程时统一结算。允许跨多次游玩继续，不要求一次连续玩完。长期挑战来自有限补给、地区条件和目标组合，不依赖战斗或丢失旧收藏。

长线远征是可分段继续的主动探索；挂机远行则是安排后按时间推进的另一种冒险方式，两者不混用进度与奖励记录。

### 基地经营

每个地区设置有限、可见的建设阶段：

- 修复落脚点，开放休整与地区互动。
- 完成实用设施，改善行囊准备、线索获取或伙伴服务额度。
- 建设特色空间，展示收藏、留下伙伴回忆并承接地区委托。

建设需要实际探索取得的地区进度或材料，不能只用囤积金币瞬间完成。基础路线与必需功能可通过普通资源开放，金苹果投入高级可选项目。

设施改善服务额度不意味着无限刷新补给或无限恢复；每趟效果与上限需在配置中明示。

### 伙伴委托

基地提供采集指定产物、调查地标、携带料理拜访、串联地区送达物品等目标。委托明确说明目的地、交付内容与奖励，接受后不过期。

委托引导玩家重新访问不同地区。先提供有限的故事委托，之后由已有目标模板组合出可重复委托；普通重复委托奖励资源，首次故事与收藏奖励只发一次。

### 持续游玩的支撑

有限建设完成后，仍可通过不同远征目标、路线条件、伙伴委托及收藏缺项继续游玩。地区各有用途，不让最后一张地图全面取代前面的产出。

满级后，小心心仍可用于伙伴运输及可选纪念项目；金币承担补给和建设，金苹果提供特殊探索与高级项目价值。已有共同纪念进度保留，可关联旅行展示成果，不重置或追缴旧投入。

整体循环为“委托给出目标 → 准备长线远征 → 收获地区物资与发现 → 建设改善下一次准备 → 继续不同路线和委托”。不把终局压缩成单纯反复捐资源，也不要求每日跑遍所有基地。

## 五、接入原则与验收

### 正式实现的最小接入

新增独立冒险状态，最小覆盖：地区进度、当前行程与行囊、固定遭遇、待结算奖励、基地项目及委托。与现有背包、奖励统计、存档迁移和伙伴身份接入，不复制一套生活属性或货币。

- 每个节点选择后保存；关闭应用不自动推进手动探索、不重抽遭遇。
- 手动探索保留现有生活时间结算，恢复时重新检查状态；挂机远行另按计划行程结算。
- 日程、睡眠与冒险明确互斥；冒险期间使用行囊补给，厨房制作等照顾活动在返程后进行。
- 出发角色与偶遇伙伴按稳定身份记录，切换外观不改变行程参与者或奖励。
- 物品转移、运输付费、事件交付及返程奖励保证一次性结算；仓库达到现有容量上限时保留待领取物资。

### 后续功能验收

必要验证覆盖：无工具绕行、食物引诱、状态不足返程、未用物资归还、购买与运输容量检查、库存不足不扣费、中断续玩、重复操作不重复奖励，以及旧存档兼容。

经济验收同时检查普通玩家的补给负担、老玩家成长优势、远征净收益和金苹果用途之间的取舍。画面、移动端触控与实际探索节奏由用户人工验收。
