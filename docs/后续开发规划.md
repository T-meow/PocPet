核心循环：

**社区提出需求 → 探索取得发现与物资 → 社区修复与种养 → 钓鱼／料理加工 → 自用、交委托或经营 → 扩建社区并准备更远探索。**

社区提供长期生活与生产目标；野外提供新品种、限定食材、发现和路线选择。每项建设应同时带来可见变化与实际功能。已建成果长期保留，不通过离线损坏或强制维护费制造日常负担。

玩家可以侧重探索、种植、垂钓或经营，通过选择不同委托参与循环。单次游玩有小成果，几次游玩完成一项修复，长期目标覆盖地区故事、社区项目、收藏和远征。

## 3. 冒险中的属性与健康强制返程

### 3.1 属性职责

| 属性 | 建议作用 | 配套应对 |
| --- | --- | --- |
| 饱食 | 推进与部分遭遇的固定成本 | 主食、途中料理、合理安排喂食；沿用吃撑保护 |
| 体力 | 行动、攀爬、调查、运输等成本 | 体力用品、适合的料理、每趟有限的营地休整 |
| 心情 | 遭遇反馈、伙伴互动与部分可选支路条件 | 趣味发现、休整、心情用品、喜好料理 |
| 健康 | 继续远行的底线，参与明确标注的风险与恢复 | 护理用品、避开风险路线、及时返回；低于撤退线自动返程 |
| 清洁 | 沿用生活变化，少量泥地／雨天等情境影响 | 护理与返程照顾，首期不新增独立强退条件 |

心情首期接入节点效果、状态显示与清楚标注的可选条件。低心情提示休整，部分支路可以暂不开放，但始终保留普通通过或返回方式；主线关键发现不依赖高心情抽奖。心情不额外套用一层全局收益倍率，也不单独触发强退。

健康不必在所有节点固定扣除，可由明确的涉水、恶劣环境、疲劳遭遇或选择造成变化。提前展示已知成本和风险范围；新手路线提供健康风险较低的选择。强退是既有状态变化的结果，不另加一次随机死亡／掉装备惩罚。

### 3.2 首轮阈值（A 阶段已采用，仍可调优）

所有比例使用该属性当前有效上限计算，包含等级、冒险成长及适用加成，不能使用固定的 100 点，也不能拿体力上限作健康分母。

| 条件 | 首轮候选 | 行为 |
| --- | --- | --- |
| 健康允许出发 | 健康 ≥ 40% | 与饱食、体力和忙碌状态一起检查；不足时先在家恢复 |
| 健康预警 | 健康 < 35% | 显示当前比例、撤退线及护理／返回入口 |
| 健康强退 | 健康 < 20% | 自动结束当前冒险，进入安全返程结算 |
| 低心情提示 | 心情 < 30% | 给出休整建议和具体选项限制，不单独强退 |

首轮采用 40%／35%／20%／30%，集中配置在 `adventureReturn.ts`。强退采用严格小于关系：恰好 20% 不强退，低于 20% 强退。出发线高于撤退线，用于避免刚回家就以极低健康反复出发。

### 3.3 判定时机与操作顺序

1. 出发前完成生活时间结算，再检查实际状态与出发线。
2. 途中每次行动、补给、交易和恢复前，先结算时间并检查是否已触发强退；已经低于撤退线时先返程，不允许在失效行程中先用药绕过判定。
3. 合法节点操作将成本、效果、发现、目标进度一次结算，再检查健康；若越过撤退线，立即生成返程结果并清除进行中的行程。
4. 时间推进、回到前台、读档和离线恢复也必须执行同一规则，不能依赖页面打开或动画结束才触发。
5. 离线结算需识别首次跨越撤退线的时刻；之后按返程后的生活规则继续推进，不能只检查离线结束时已自然恢复的健康。
6. 强退之后取消尚未提交的推进／补给动画和旧回调；重复点击、重载与重复结算只产生一份返程回执。

健康预览明确显示当前值／上限／比例。已知某选项结算后会低于撤退线时，选择前显示“完成此行动后将返回”，不隐藏确定的后果。

### 3.4 强退后的物资、任务与奖励（建议）

- 强退不收取额外饱食、体力、金币或小心心；使用现有健康下限，不新增角色死亡规则。默认回到前哨／安全大厅，后续长线远征可对应最近的安全基地。
- 行囊中已携带物品及工具默认保留，满仓物资留在待领取结果中。用户无需先清空仓库或处理地面物资才能离开危险状态。
- 未拾取的地面物资不自动进入仓库。建议返程页提供一次整理机会，可主动替换所携物品；原行囊与地面物资合计按返程瞬间的行囊容量选择带回组合，工具独立计数。超过容量的部分明确放弃，不能靠分批入库或先兑换绕过携带上限。该体验需专项验收。
- 建设关键线索与一次性发现独立记入永久进度，不能因包满、误卖或强退丢失。需要实物交付的普通委托仍检查实际物品。
- 未完成行程按提前返回结算已获得收获，不发完整通关奖励、不占用“已完成”的每日次数。
- 如果最后节点已经合法结算并达成终点，随后健康触发强退，仍按真实完成状态记账；完成日沿用节点达成时的日期，不能通过强退或跨日重复领取。
- 委托中已完成的调查／寻找事实保留，未完成部分可继续；纯运输目标需实际送达才能完成。

这些规则要求复查现有“地面物资未处理不能返回”和“满仓分批领奖”路径，为健康强退提供可立即退出活动状态的处理方式。

### 3.5 补给与吃撑保护的衔接

目前行囊的恢复品筛选主要接受饱食或体力恢复物品。接入新参数时，须同步允许适用的纯健康、纯心情用品，并统一恢复预览、实际效果和容量规则。

普通食物仍受吃撑保护；护理品与纯体力用品提供独立恢复途径。金苹果、生日蛋糕继续遵循各自特殊使用规则，不因本次规划自动扩大其携带范围；生日蛋糕目前不属于冒险补给。物品交付、诱饵和建设投入不触发食用效果。

## 4. 冒险带来的永久成长

建议按属性独立保存有限加成：**有效上限＝等级基础＋冒险里程碑加成＋适用的已有加成**。展示来源，避免玩家只看到总数变化。

- 新手探索、路线首次完成：优先饱食与体力成长。
- 地区故事、伙伴共同经历：可提供心情成长。
- 野外生活与地区建设目标：可提供健康、清洁等成长。
- 地区阶段完成：给予一次综合成果，可组合属性、配方、设施或纪念。

增长主要绑定首次成果与有限累计里程碑；每日重复委托不无限增加属性上限。已有存档仅凭可信记录补发已达成成果，不用最近八条手账猜测全部历史。

B 首组已实现：首次踩点 +3、首次溪谷完整探查 +5、建成菜地 +4、首次暖粥交付 +3，均为体力上限，共 +15。直接从永久完成／建设记录计算，重复操作不累加；旧档可靠的通关记录自动生效。新增容量不立即回满。首组只增加体力，其他属性奖励留给后续里程碑；等级基础倍率保持不变。

新增上限与日常衰减、互动收益、冒险心心倍率分开核算，避免加了上限又同比增加消耗。同一路线成本保持固定，高成长玩家能够减少补给并腾出行囊空间。成长奖励是否同时补充新增容量，需在首轮数值表中明确。

## 5. 社区建设与野外建设

### 5.1 社区设施及前置

| 项目 | 关键发现示例 | 建议前置 | 建成后的变化 |
| --- | --- | --- | --- |
| 菜地／温室 | 灌溉阀芯、种植线索 | 照顾教学完成后可起步 | 开放菜地，接纳探索种子 |
| 钓鱼小屋 | 栈桥修复图纸、旧钓具 | 可与菜地独立起步 | 开放基础水域、基础钓竿与鱼饵 |
| 鸡舍 | 饲喂装置零件 | 菜地及相关修复目标 | 提供鸡蛋与养殖玩法 |
| 牛棚 | 饮水设备 | 鸡舍及对应地区线索 | 提供奶类原料与养殖扩展 |
| 上游步道 | 水域勘测记录 | 钓鱼小屋 | 开放新钓点及鱼种 |
| 厨房加工设施 | 配方、器具或技术线索 | 对应生产来源可用 | 开放新加工方式和配方 |
| 小摊与公共空间 | 建设材料、社区项目成果 | 基础生产及相关目标 | 出售余量、展示收藏、承接活动 |

沿用原型中“菜地→鸡舍→牛棚”和“钓鱼小屋→上游水域”两条发展线；具体项目顺序可随内容调整，不预设统一高等级门槛。

建设采用“关键发现＋具体社区修复工作＋材料／金币”的组合。探索关键物可通过常驻目标稳定取得，修复工作复用现有社区工作能力并明确实际任务，不另外增加一套无内容的贡献次数。

首期固定建筑位置，每处配置少量清楚的建设阶段。每阶段明确场景变化、功能、成本和后续目标；建成后即可使用。

### 5.2 野外设施与社区互通

野外营地提供有限休整与分段停留；桥梁和步道改变通行；地图桌提供线索；补给站改善商品种类及运输能力。每趟恢复、服务额度都有明确限制。

社区生产支持远征准备，野外发现支持社区升级。物资继续共用仓库，不为每个基地复制独立经济。已解锁基地可直接回访，单纯回访不要求重新跑完整路线，也不领取探查通关奖励。

## 6. 农场、探索种子与养殖

现有种植园作为果园分区保留，逐步加入菜地、养殖与必要的加工能力，已有树木、工具和成果不清空。

| 来源类型 | 建议获取方式 | 持续用途 |
| --- | --- | --- |
| 常见作物 | 商店常驻种子／现有材料渠道 | 基础料理、一般订单 |
| 探索品种 | 在指定地区找到种子；商店不卖 | 带回菜地培育，形成新的生产能力 |
| 野生限定食材 | 对应地区定向采集，部分不可种植 | 地区料理、特殊订单与远征 |

探索品种建议采用“永久发现记录＋实际种子库存”：首次探索取得种子，收获时可以牺牲一部分产物留种；正常种植提供可靠的续种方式，具体数量待核算。种子用完后可按手账线索重新定向寻找，不能永久失去品种。关键种子不依赖每日委托随机刷出。

种子与对应食谱或其他用途一同上线。菜地面积与作物生长周期促成种植选择，不用无限增殖种子制造无限收益。保留野生采集专属产物，使成熟农场之后仍有探索目标。

养殖配置饲料、生产周期和储存上限，缺料／满仓时暂停生产；长期离线不让动物死亡或追回已有产物。具体照料减时与额外产物沿用技能／奖杯规则核算，不能直接将所有产量翻倍。

## 7. 钓鱼小屋与水域发展

- 探索找到修复线索，社区工作与建材完成小屋；随后通过步道／勘测项目开放更多水域。
- 保留手动选水域、准备鱼饵、抛竿、等待咬钩、收线与松线的基本体验。离线／快进不自动产鱼，除非以后另行定义并授权独立自动作业。
- 水域、鱼饵与钓具决定可遇见的鱼种及体验，先提供常见鱼稳定产出与少量珍稀收藏。
- 普通鱼用于料理、一般委托与出售；珍稀鱼用于图鉴、展示、可选长期目标和特定买家。
- 图鉴保存首次发现、累计收获与最大记录，消耗／出售实物不删除收藏记录。
- 日常委托优先采用可合理取得的常见鱼或明确水域调查；关键进度不要求低概率珍稀鱼。
- 钓鱼小游戏与冒险分别记录活动状态和结算；本轮健康强退针对冒险，不能自动推导为所有社区小游戏的惩罚。野外钓点若嵌入冒险，则服从所在行程的健康规则。

## 8. 每日委托与常驻目标

统一在社区公告板查看，区分长期建设／故事目标和每日候选委托。候选首版可设每日 3 项、选择 1～2 项，具体数量待体验验证。

| 类型 | 示例 | 验收事实 |
| --- | --- | --- |
| 寻找道具 | 找回旧桥附近的工具包 | 接取后在目标点完成搜寻；不能用商店同名物品替代 |
| 实地采集 | 到溪谷采集新鲜香草 | 接取后于指定地区取得所需产物 |
| 物资交付 | 为鸡舍准备一批原料 | 可使用旧库存，交付时实际扣除 |
| 钓鱼调查 | 在上游钓获一条常见鱼 | 指定水域的有效垂钓结果 |
| 料理订单 | 准备两份鲜鱼汤 | 提前说明是“新制作”还是“交付现有料理” |
| 拜访送达 | 把便当送到野外营地 | 带物品抵达并完成交付 |

规则建议：

- 沿用游戏日凌晨 5 点边界刷新未接取候选。已接取任务保留到完成或主动放弃，跨日补交不占用新一天的接取额度。
- 仅从已开放地区、设施和可取得产物生成候选；任务明确目标、来源、成本提示与奖励。建设前置不会反过来要求尚未开放设施的产物。
- 普通寻物任务有明确线索和稳定结果；不可通过反复返回、读档或刷新无限重抽奖励。
- 候选、目标进度和领奖各使用稳定记录，一次交付与扣物／奖励一起结算。同一份交付物不能同时支付给两个委托或出售。
- 建设关键图纸、必需种子和主线故事提供常驻入口，不放在每日随机候选里作为唯一来源。
- 已完成当天溪谷探查后，仍可进入低消耗委托短路线；其奖励不重复发放完整探查礼包。普通探查也可顺路完成对应委托。
- 委托短路线不产出完整路线的终点战利品；可采集资源与任务奖励单独配置，防止反复提前返程复制收益。
- 领取前展示奖励和库存容量；容量不足保留待领，不吞物品。强退保留有效进度，未送达目标不算完成。

商店新增条目时，复查现有收集成就和“任务大师”的固定目标，不能让旧玩家已完成的目标因新品上架失效。日常新功能先接中文，英文可回退中文；不为补翻译调整版本。

## 11. 摆摊、工会回收与经济关系

- 摆摊售价以出售基价为基础，叠加已确认的 20% 基础增值、知识与摊位建设影响；知识和建设的具体档位另定，原型 20%～40% 示例不是正式上限。
- 上架固定报价，后续升级影响新上架批次。普通物品受总客流与货架容量限制，珍品需要对应买家；产量、知识和客流分别核算。
- 食物恢复倍率不乘进卖价；料理制作心心不在出售时重复发放。园艺额外掉落也不直接转换成成交速度。
- 工会回收提供明确基价；金币堆保持固定兑换用途；关键发现不可误卖，普通建材和珍品允许设置保留数量。
- 复查商店买入→制作→出售的净收益，允许有计划的经营利润，但必须计入原料、加工奖励、产能、客流、折扣与库存约束。
- 金币支持采购／建设／服务，小心心支持既有成长和运输，金苹果保留既有用途，并用于明确的高级可选建设／特殊探索。首轮不增加一套通用建设货币。

成长模型继续参考正常游玩约一年从 Lv.1 到 Lv.99、每日约 20～30 分钟操作的既有目标，保持现有升级成本；这是设计目标，需用实际上线内容重新测算，不能将未开放设施和委托收入提前计入。

## 12. 长期与终局内容

社区基础建设完成后，开放可分阶段推进的社区项目，如河岸聚餐、主题集市、鱼类展览、地区料理分享和观测站远征准备。它们组合已有种养、垂钓、料理与探索能力，接受后不过期。

首次项目提供故事、有限成长、设施／外观与共同回忆；后续举办可选择不同菜单、主题和供货目标，提供资源及收藏进展。图鉴、配方、品种和回忆记录在实物消耗后保留。不同玩法偏好可选择不同目标，不要求每日跑遍所有设施。

跨地区远征逐步串联 2～3 段候选路线，允许多次游玩完成；地区基地承担有限休整和返程。后期取舍来自目标组合、工具、行囊与补给，高等级和旧奖杯仍使旧路线更轻松，不能随玩家等级等比提高所有消耗。

挂机远行与手动探索分别设计时间、成本、恢复和奖励。手动行程离线不自动推进节点；未来自动作业需要独立结算定义，不能直接套用原型快进。两种方式都要明确健康检查、提前结束和一次性奖励规则。

## 13. 建议开发阶段与交付标准

| 阶段 | 主要范围 | 阶段完成标准 |
| --- | --- | --- |
| A：冒险状态完整化 | 心情／健康参数、预警／强退、护理品携带、少量相关商店商品 | 出发、途中、离线、强退与满仓结算完整；吃撑时有适用恢复手段 |
| B：第一条社区生产循环 | 社区建设记录、寻物委托、菜地修复、一种探索种子、对应料理与交付目标 | 玩家能从发现走到生产、加工与交单；首次成果带来有限冒险成长 |
| C：农场与钓鱼扩展 | 鸡舍／牛棚逐项接入；钓鱼小屋／基础水域／上游／鱼类料理逐项接入 | 两条发展线可独立体验，产物、解锁、容量与存档都有实际闭环 |
| D：日常委托与经营 | 更多委托模板、小摊、工会回收、自用保留、知识／摊位建设、配套商品 | 任务跨日稳定，交付与出售不重复耗物，生产和客流收益可核算 |
| E：地区与终局 | 多地区特色产物、野外设施、长线远征、社区项目；另行接入挂机远行 | 基地建成后仍有可选择目标，地区各有用途，已有成长与收藏长期有效 |

阶段内按可体验的小批次交付，不将所有设施一次打包开发。建设、探索种子与料理应成组上线；商店货品随对应玩法扩充。永久成长在阶段 A 梳理上限与倍率接口，在阶段 B 接第一组实际里程碑。

首条体验样例：**溪谷寻找灌溉零件和香草种子 → 完成社区水渠修复 → 菜地种植并留种 → 做出新料理 → 交付社区订单 → 收到首个建设／探索成果。** 钓鱼阶段再接入鱼获与鲜鱼料理，不为第一条循环提前依赖全部养殖设施。
