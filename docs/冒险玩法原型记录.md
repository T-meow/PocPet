## 建议试玩顺序

1. 默认 Lv.12：带绳索出发 → 溪边采集 → 旧木桥 → 观景台 → 旧温室 → 可选守卫挑战（防守／能力／防守／攻击）→ 回家收好行囊。
2. 再带放大镜出发，从采集点发现近路；手动可直达故事终点，之后远行页也能选择近路。
3. 安排 2 小时远行，摸摸／聊天，快进到收获节点后召回，或直接到家；比较完整与提前返回的结果。
4. 打开地区基地，修好屋檐、添家具、和邻居聊天，再去旅行手账查看记录。
5. 展开页底「试玩控制」，选择「五地漫游 · Lv.30」直接预览五个地区与基地；切换示例会清空本次试玩。
