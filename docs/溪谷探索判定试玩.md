# 溪谷探索判定试用版

本轮接入溪谷入口探查、七段故事、六节点完整巡路、两节点定向采集和旧桥短途。教程、轻装散步和其他地区手动流程保持原有规则。其他地区已建立难度配置，具体剧情接入留待后续。

## 本地启动与入口

在项目目录运行 `npm.cmd run serve:local`，浏览器打开 <http://127.0.0.1:5173>。使用现有前哨基地入口进入；首次游玩先完成「踩点探索」并领取行囊。

- 入口探查：前哨基地 → 总地图 → 溪谷入口 → 出发整备。
- 七段故事：完成一次溪谷入口探查并领取后，从溪谷地图依次选择故事节点。
- 完整巡路、定向采集：溪谷地图中的巡路／采集入口 → 巡路整备 → 选择完整巡路或定向短途。海蓝宝选「海蓝宝勘探」。
- 旧桥短途：旧桥或委托入口中的短途搜寻。
- 补给：行程中的行囊与途中补给；休整：完成一地巡路后进入营地。

已经在途的旧行程会继续采用原规则。完成并领取旧行程，再出发才能体验新版判定。新溪谷探查为版本 9，溪谷手动远征为版本 4；临时准备在结束行程或离开溪谷时清除。

## 人工试玩清单

界面布局、视觉效果、手机触摸操作由人工验收；本次没有自动截图或使用 Computer Use。

1. 带一份料理、心情补给和护理用品出发。确认选项显示主技能、当前／推荐等级、顺利以上概率、四档结果、体力和健康范围、收获范围、工具耐久。
2. 心情约 20% 时出发（健康仍需至少 40%）。确认危险选项可选，概率降低、体力和伤害倍率提高；途中使用心情补给，预览立即更新。
3. 全程选择稳定路线，完成入口和七段故事。应无随机伤害、不获得判定经验；剧情线索、设施资格、首次剧情物品照常保留。
4. 尝试普通采集、建材采集和海蓝宝。对应园艺 1 级、运动 2 级、学习 3 级；受挫仍推进，采集机会照扣，收获／调查进度按结果变化。
5. 携带探路绳经过浅滩；有放大镜、镰刀、手镐时选择工具辅助。检查成功率变化、一次耐久消耗和最后一次使用后的损坏说明。绳索失手伤害减半。
6. 路标观察顺利或出色后，确认「观察准备」分别持续 1 或 2 次判定；稳定通行不消耗准备次数。
7. 在温室手账或营地故事第二节点选择行囊料理。确认只消耗一份、立即按现有规则恢复，并显示后续减耗。吃撑时该选项不可用。普通行囊食用只恢复状态，备餐判定才产生临时减耗。
8. 当体力低于选项展示的最坏消耗时，选项应禁用。补给后重新开放。背包满时应保留待整理物资，不能重复领取首次成果。
9. 危险行动可能使健康低于 20% 时应显示预警；若实际触发，结算后安全返程，保留已完成进度和判定摘要。普通行动、稳定路线不会直接损伤健康。
10. 在同一节点刷新、导出后导入、冻结／恢复时间，观察同一选项在相同状态下的结果不变。补给可以改变成功阈值，不会换骰。连续点击不能重复扣费、获得经验或领奖。

## 验证入口

`npm.cmd run check:exploration-checks` 检查公式、边界、五地区越级限制、心情插值、稳定路线、受挫推进、七段故事、采集与调查、临时增益、工具、升级、返程、原子性和存档。样本表会在检查结束时输出。

原有固定成本断言通过 `scripts/fixtures/legacy-exploration.ts` 显式创建旧版探查／手动远征，避免将旧版期望套用到新版随机消耗。原有教程、时间冻结、补给、工具、技能和存档检查继续独立运行。

溪谷循环中的餐包退款断言明确使用旧版分段餐包存档；当前整趟配餐由已有的 `check-idle-rations.ts` 单独验证。保留工作区现有的前哨界面、配餐和存档压缩改动。
