# 1.6.1 客户端更新与存档界面

- [x] 客户端设置加入检查更新：默认每天一次，支持手动检查、更新说明、稍后提醒、忽略版本和按平台架构下载；网络失败不影响游戏。
- [x] 仅使用正式 GitHub Release，校验稳定版本号、官方链接和对应产物；旧 Release 无法确认架构时提供发布页入口。发布时补充更新清单，不改变八种交付包的名称。
- [x] 更新只打开浏览器下载入口，不自动安装；下载前提供备份入口。旧版 Android 提示测试签名的首次迁移要求，网页和 B 站版不显示客户端更新入口。
- [x] 云存档仅在 B 站版且运行时可用时显示，隐藏不可用区域及提醒设置；统一存档页的分区、按钮、文件选择和文本框样式。
- [x] 类型、更新选择逻辑、存档回归及桌面/手机模拟界面验证已通过。本轮不启动发布打包、GitHub CI，不自动提交或推送。

已获授权的两个 Android 固定测试签名 Secret 已配置。用户随后要求上传 GitHub，本次上传包含客户端更新、存档界面及固定签名适配；提交使用 `[skip ci]`，发布和打包继续暂停，不创建版本标签。

原生网络使用 reqwest + Rustls 公共根证书，避免 WebView 跨域和 Android 系统证书桥接依赖。新增 Rust 依赖及锁文件已同步。模拟验证不代替真机安装、系统浏览器唤起和覆盖升级验收。
