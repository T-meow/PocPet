# 手工台配方与售价

厨房的「手工台」制作独立售卖商品。每批1–999件，只消耗清单中的材料，不额外扣金币、发心心或触发赠礼效果。成品不可喂食，也不提供永久装饰加成。

## 副产物回收

每实耗3个生鸡蛋回收1份蛋壳，每实耗2份蛤蜊回收1份净贝壳。只统计料理扣除的原始材料，前序成品不重复产生副产物。不足一份的进度跨批次保存，批量与分批制作的回收量相同。

副产物优先进入仓库，放不下时保留在手工台待领。部分领取后剩余数量继续保存，读档和重复点击不重复产出。蛋壳与净贝壳不单独出售。

## 配方与当前价格

材料计价中，采集物、地区珍宝、副产物和商店心情类商品增加30%；木料、石料、面粉等其他材料按原估值。总计价成本再加60%工艺收益并向上取整，摆摊加成另计。内部计算保留精度，下面的计价成本显示为整数。九款商品均满足利润严格超过计价成本50%的🪙标识条件。
