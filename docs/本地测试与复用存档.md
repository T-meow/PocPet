# 本地测试与复用存档

本地测试统一入口为 **http://127.0.0.1:5173**。使用 `npm.cmd run serve:local` 或 `npm.cmd run dev`；占用时检查并复用已有本项目服务，不换端口。预览服务也使用同一端口，不能与开发服务同时启动。启动脚本关闭旧的一次性自动解锁开关。

## 全设施基准存档

执行 `npm.cmd run save:test:facilities`，生成 `output/test-saves/full-facilities.pocpet.json`。打开测试页面，在「设置 → 存档与恢复」中导入该文件并确认替换。想恢复测试基准时再次导入同一文件即可，导入会把运行时间基准调整为当前时间。

- 社区菜地、鸡舍、牛棚、小摊为 3 级，钓鱼小屋 5 级；上游、林地深潭、海岸栈桥已开放。
- 果园全部地块开放，园艺工具 3 级；厨房设备齐全，全部作物可种植。
- 五个地区的故事已完成，各据点 2 级；溪谷七段剧情已完成，背包 72 格。
- 宠物总等级和学习、园艺、运动、烹饪技能均为 1 级。配方继续遵守自身规则；技能可通过正常玩法成长。
- 100,000 金币、1,000 爱心，包含工具、种子、树苗、建材、食材和探索补给。健康与体力充足，心情和饱食为 80%，无进行中的任务或远征。

这是用于复用的合成测试存档，不包含个人存档内容。生成器使用正式导出/导入流程验证，并检查延后 180 天导入仍保持初始健康与体力。生成物位于已忽略的 `output/`，生成器和本文档纳入版本管理。

若要测试溪谷首次剧情与首次奖励，请使用清空后的新档；本文件用于直接体验设施和常规探索。
