# 安卓状态栏安全区修复

## 目标与授权

2026-09-19：用户反馈安卓 App 显示状态栏时遮挡顶部设置一行，授权检查并修复。单助手，只改本地代码并作必要检查；保留现有标签、社区服务、音频、存档等未提交改动。不提交、不发布、不打包、不操作设备／截图，画面由用户人工验收。

## 判断与决定

- 正式 UI v2 在默认、1050px、600px 三档都用顶部为 0 的 padding 覆盖通用页面安全区；改为已有的 `--safe-top`，没有安全区时仍为 0。
- 安卓 `targetSdk = 36`，`MainActivity` 此前只设置 WebView 缩放，没有系统栏 inset 处理。原生内容容器监听可见系统栏与屏幕缺口的实际 inset，按绝对值更新四边 padding，覆盖顶部栏、页面及弹窗；状态栏隐藏时更新为当前安全区，不累加留白，不使用固定高度或 UA 猜测。
- 已处理的 inset 类型置零后继续向 WebView 分派，避免新 WebView 与 CSS 重复留白；键盘 inset 原样传递。沿用原来的窗口模式，不强行开启沉浸或隐藏状态栏。
- 官方依据：[Android WebView window insets](https://developer.android.com/develop/ui/views/layout/webapps/understand-window-insets)、[Android edge-to-edge](https://developer.android.com/develop/ui/views/layout/edge-to-edge)。
