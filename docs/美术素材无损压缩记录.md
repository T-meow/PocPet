## 处理原则

- 图标接入：使用已确认的 `output/imagegen/adventure-icons-20260917/adventure-icons-raw.png`，按真实空白切分、去除背景，输出 256×256 透明母版及 128×128 游戏用图，保持道具 ID 与 Mod 覆盖能力。
- 轻度压缩：保留尺寸、透明度与原有色彩配置。展示用图采用高质量 WebP；需要兼容保存的 CG 保留 PNG 并尝试高质量调色板压缩。已有原生 PNG／ICO／ICNS 优化保留，不改平台要求的格式。只写回更小且质量检查通过的候选。
- 原始生成图、历史美术来源与压缩前备份保留在 `output/`，不打入游戏。只对实际运行素材进行压缩；新图标切分／去底／缩放属于已获授权的接入加工，和既有素材的无损压缩分别记录。
- 先准备完整候选和校验记录，再按确定清单写回；写回前核对源哈希，写回后再次核对文件哈希，避免覆盖并发改动。涉及引用更名时同步检查所有运行引用。
