# PocPet Toy SDK 测试清单

## 本地检查

依次执行：

```powershell
npm.cmd run check:toy
npm.cmd run check:save-recovery
npm.cmd run check:gacha
npm.cmd run build
npm.cmd run build:toy
```

确认普通构建的 `dist/index.html` 不含 `toy-sdk.js`，Toy 构建只含一次官方 SDK 脚本，HTML、JS、CSS、图片和音频均使用相对路径。

## 云存档

1. 在已登录的 B站 App 打开设置 > 存档，确认显示 Toy 云存档状态。
2. 首次上传并确认；记录宠物名称、等级、上传时间和分片数。
3. 修改少量进度后再次上传，确认状态更新时间且本地进度不受影响。
4. 在另一台已登录同账号的设备打开预览，确认读取到最新云端清单，再执行恢复。
5. 恢复后应先出现导入预览；取消时本地不变，确认时产生“导入前备份”。
6. 导入旧版原始 JSON 或旧 `.pocpet` 文件，确认一次性转换成功，之后仍可上传云端。
7. 未登录或断网时确认云操作给出失败状态，不显示无效的到期提醒，也不修改本地存档。

## 备份提醒

1. 使用创建超过 3 天且从未上传的旧存档进入 Toy，确认首页出现非阻塞提醒、设置按钮有红点。
2. 直接关闭后，当天不再弹出，但设置红点保留。
3. 选择“7 天后提醒”后，提示和红点都消失。
4. 在设置关闭“云存档提醒”，确认提示和红点隐藏；重新开启后立即重新计算。
5. 上传成功后确认当前提醒消失，下一周期以云端 `uploadedAt` 为准。

## 分享与纪念

1. 生成当前宠物档案卡，确认尺寸为 3:4，包含五项状态、资产、背包、成就、抽卡、花园、专注和三个可解释标签。
2. 有年度回顾的存档关闭回顾后，在设置 > 分享与纪念继续导出最近年度纪念卡。
3. 完成单抽和十连后分别保存结果卡，检查机器、奖励、稀有度、大奖或保底标记和时间。
4. B站 App 应保存到相册；Toy Web 应下载 JPEG。图片有平台二维码时，扫码应回到当前 Toy 首页。
5. B站 App 点击“分享 PocPet”应打开分享面板；Toy Web 应显示二维码和平台链接；普通本地 Web 不应分享本地地址。

## 作者与关注奖励

1. 作者卡只打开作者空间，视频卡只打开 `BV1zmTX6iEgn`。
2. 未关注时从作者空间返回，不发券并提示未检测到关注。
3. 关注后返回，确认发放 10 张扭蛋券并显示奖励弹窗。
4. 再次打开作者空间或重复导入旧存档，不应重复发券；本地领取状态应由云端标记补回。
5. 曾领取旧 `author-link-gacha-ticket-gift-v1` 的存档仍可领取一次新的关注奖励。
