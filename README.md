# PocPet

[English](README.en.md)

**把远方带回日常。**

PocPet 是一款离线优先的虚拟宠物养成游戏，支持桌面、Android 和网页。照顾小窝里的伙伴，带上亲手做的料理去远行，再把收获带回农场、餐桌和纪念册。

希望虚拟的陪伴可以抚平孤独的灵魂。

## 和伙伴一起生活

- **日常陪伴**：喂食、清洁、休息与玩耍，完成每日愿望，培养学习、园艺、运动和料理技能；也可以开一段番茄钟，或一起听音乐。
- **五地探索**：从溪谷出发，走过风车山丘、雾松林地、潮汐海岸与旧观测站，探索 40 个地标，发现故事、物产与珍宝，建设营地并安排挂机远征。
- **溪畔农场**：种植 16 种作物，照料果园、鸡舍与牛棚；前往四处水域，收集 18 种鱼和金冠纪录。
- **厨房与小摊**：加工自己的食材，解锁 63 道食谱，制作料理、准备旅途补给，或把收获上架售卖。
- **邻里生活**：接取委托和特产订单，筹备聚餐、展览与星空之夜，制作可升级的装饰，让旅途与农场彼此相连。
- **收藏回忆**：收集成就、奖杯、节日故事与纪念 CG，通过 Mod 定制伙伴外观和文本。暂时忙碌时，可以备份后冻结时间，回来再继续。

## 开始陪伴

| 入口 | 说明 |
|---|---|
| [下载客户端](https://github.com/T-meow/PocPet/releases) | 查看正式更新公告，下载适合设备的安装包 |
| [网页版](https://t-meow.github.io/PocPet/) | 在浏览器中直接游玩 |
| [B 站 Toy 版](https://www.bilibili.com/toy/pocpet/index.html) | 使用平台登录、云存档与分享功能 |
| [本地开发与试玩](docs/本地测试与复用存档.md) | 从源码启动，使用固定测试入口与可复用存档 |

第一次远行可以从前哨的「踩点探索」开始，完成并领取行囊后，逐步开放地图与农场设施。各玩法的说明按钮可查看条件、消耗与奖励。

在「设置 → 存档与恢复」中备份或迁移进度。不同设备、浏览器来源和客户端的本地存档各自独立；使用 Mod 时请同时保留原 Mod 文件，存档不包含其中的图片。B 站版的差异见 [Toy 平台使用参考](docs/Toy平台使用参考.md)。

玩法数值、代码结构、打包与素材规范见[参考文档](docs/README.md)；当前源码版本以 [package.json](package.json) 为准，已发布版本以下载页为准。
